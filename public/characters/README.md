# Memory friends v1

Original 30-character illustration atlas generated with the built-in image generation tool. Six columns, five rows; row-major order matches `characterAnimals` in `lib/character-style.ts`. Keep this order stable for existing IDs. Rendered as CSS sprites and drawn from the same atlas during PNG export. User-generated profile portraits remain separate.

Prompt: A regular 6×5 atlas of original Korean indie stationery animal mascots. Lovably awkward deadpan expressions, rounded bodies, hand-drawn brown pencil outlines, subtle gouache paper grain, dusty pastel colors on warm ivory. Each animal has one unexpected accessory: toast cat, flower dog, riceball otter, carrot rabbit, swim-goggle bear, cookie hamster; scarf fox, coffee panda, sleepy koala, camera raccoon, acorn squirrel, flower hedgehog; sock-antler deer, pillow sloth, ribbon tiger, sunflower lion, party elephant, scarf giraffe; earmuff penguin, fried-egg duck, crooked-glasses owl, teacup chick, ballet flamingo, sideways-cap parrot; tangerine seal, sailor dolphin, flower-spout whale, plant turtle, flag octopus, oversized-crown frog. Equal cells, no text, no grid lines, no overlaps, no stock emoji or glossy 3D.
