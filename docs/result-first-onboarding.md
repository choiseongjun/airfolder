# 결과물부터 시작하는 메모네스티아

작성일: 2026-10-21

## 후속 개선: 기존 앨범 테마를 첫 화면으로
- 색상만 다른 네컷 카드 대신 기존 앨범 렌더러를 사용해 보딩패스, 추억 영수증, LP, 매거진, 생일, 필름을 먼저 보여준다.
- 전체 보기에서 기존 14개 테마를 선택할 수 있다. 테마 이름과 설명은 기존 앨범과 공통 정의를 사용한다.
- 선택한 테마로 내 사진을 미리 보고, 서버 저장 시 해당 앨범 테마와 원본 사진을 함께 저장한다. 테마 앨범에는 별도의 네컷 합성 이미지를 끼워 넣지 않는다.
- 기존 네컷 카드 제작·다운로드는 별도의 접힌 영역에서 계속 제공한다.
- 저장 요청은 브라우저의 모의 API로 확인하며 검증용 사진을 운영 데이터에 추가하지 않는다.

## 문제와 가설
기존 첫 화면은 서비스 설명과 로그인을 먼저 보여준다. 방문자는 앨범·그룹의 사용법을 이해하기 전에 가입 여부부터 결정해야 한다. 예쁜 결과물을 먼저 보여주고 자신의 사진으로 바로 만들어보게 하면 사용 가치를 더 빨리 느낄 수 있다는 가설을 검증한다. 다른 서비스의 스크린샷만으로 실제 사업 성과를 단정하지 않는다.

## 첫 실험 범위
- 친구와 하루: 크림색 네컷, 같이 보낸 하루를 한 장으로.
- 생일 축하: 로즈색 네컷, 축하 문구가 들어간 카드.
- 여행 네컷: 민트색 네컷, 여행 사진 네 장을 한 장으로.
- 완성 예시 선택 → 내 사진 최대 네 장 선택 → 실시간 결과 확인 → 이미지 다운로드·공유 → 앨범에 보관 → 친구 초대·롤링페이퍼로 연결.
- 사진 선택·카드 제작·다운로드에는 로그인과 서버 사진 업로드가 필요하지 않다.
- 서버 앨범 저장은 기존 세션·이용 규칙 확인 후 진행한다. 동의 취소·통신 오류 시 선택 사진을 유지한다.
- 기존 로그인·초대 링크 진입은 보조 동선으로 유지한다. 기존 회원의 홈 피드는 바꾸지 않는다.
- 기존 스튜디오의 프레임·색상·문구 편집은 ‘문구와 분위기 바꾸기’ 안에 제공한다.
- 참고 앱의 이미지·프레임은 복제하지 않고 기존 프로젝트의 공개 소개용 사진과 자체 프레임을 사용한다.

## 측정
기존 유입 → 로그인·가입 → 앨범 생성 → 초대 링크 생성 집계는 유지한다. GA 선택 동의 이용자에 대해 template_selected, card_preview_ready, card_downloaded, card_shared 이벤트에 세 가지 template_id만 기록한다. 사진·파일명·사용자 문구는 전송하지 않는다. 공유 취소는 성공으로 집계하지 않는다.

## 완료 기준
세 템플릿 모두 모바일·데스크톱에서 선택할 수 있고 선택한 템플릿의 문구·색상이 제작 화면에 반영된다. 내 사진으로 만든 JPEG를 받을 수 있다. 제작 전에 로그인·약관이 끼어들지 않는다. 앨범 저장 시 기존 접근 제어를 유지한다. 게시물별 성과가 나오기 전까지 대량 프레임 제작은 보류한다.
