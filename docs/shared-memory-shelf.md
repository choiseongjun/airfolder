# 제품 정의: 함께한 날을 쌓는 추억 책장

2026-10-27. 사용자가 승인한 제품 방향. 기존의 개인 추억책 중심 정의보다 우선한다.

## 누구의 어떤 순간인가

우선 대상은 함께 사진을 찍지만 서로의 사진첩과 메시지에 추억이 흩어진 커플이다. 여행·데이트를 마친 뒤 다시 볼 기록을 남기는 순간을 해결한다. 기념일 선물은 시작 계기이며 제품 전체를 선물 제작기로 한정하지 않는다.

약속은 **함께한 날을 한 권씩 만들고, 초대한 사람과 같은 책장에 쌓아 다시 펼치는 것**이다. 추억책은 결과물, 책장은 재방문할 공간, 다운로드는 가져가는 방법이다. 정리·공동 보관 수요나 유료 전환이 검증됐다고 주장하지 않는다.

## 핵심 동선

1. 소개에서 여러 권이 쌓인 예시 책장을 보고 사진 한 장으로 시작한다.
2. 사진 1~8장으로 한 권을 만든다. 문장은 선택이며, 비워두면 편지 페이지 없이 만든다.
3. 완성본을 개인 책장 또는 공유 책장에 명시적으로 보관한다.
4. 공유 책장 소유자가 초대 링크를 상대에게 보낸다.
5. 상대가 초대 범위·약관을 확인하고 참여한다.
6. 같은 책을 열어 자신의 사진과 이야기를 새 기록으로 보탠다. 원래 작성자의 페이지를 덮어쓰지 않는다.
7. 다음 날의 책도 같은 책장에 만든다.

## 현재 구현과 경계

- 기존 groups / group_members / folders / records 권한 모델을 사용한다. 별도 DB 마이그레이션은 없다.
- 새 공유 책장은 비공개로 만든다. 기존 공개 공간은 공개 상태임을 표시한다.
- 커플 중심 UX지만 인원은 기존 그룹 제한을 따른다. 정확히 2인만 허용하거나 특정 수신자만 링크를 열 수 있다고 약속하지 않는다.
- 초대 링크 소지자는 참여할 수 있다. 7일 만료, 재발급 시 이전 링크 폐기, 수동 만료를 제공한다. 참여 시 기존·향후 공유 기록 접근 범위를 안내한다.
- 개인 책은 자동으로 공유하지 않는다. 공유 책장을 선택해 저장한 새 페이지와 글만 해당 멤버에게 공유한다.
- 원본 파일을 공동 수집하는 편집기는 아니다. 현재 추억책 제작은 렌더링한 JPG 페이지와 글을 보관한다. 상대의 추가 기록도 새 JPG 페이지 묶음이다.
- 공유 책에서 여러 사람의 기록은 기록 선택기로 읽는다. 동시 공동 편집·자동 원본 통합·실물 배송·PDF 제작을 약속하지 않는다.
- 게스트는 브라우저 데이터 삭제로 접근을 잃을 수 있어 계정 연결 안내를 유지한다.
- 기존 크루/개인 데이터, 다운로드, 원본 관리 경로는 유지한다.

## IA와 시각 언어

- 주요 메뉴: 홈 / 우리 책장. 계정은 보조 메뉴.
- 책장 필터: 모든 책 / 개인 책장 / 참여한 공유 책장.
- 실제 계정 화면에는 실제 데이터만 표시한다. 소개의 책장은 예시임을 명시한다.
- 따뜻한 종이색·테라코타·세이지, 여백과 책등 표현을 사용한다. 캐릭터·보상·비하인드는 앞세우지 않는다.
- 모바일에서 선택·초대·보관 버튼과 본문이 겹치지 않게 한다. 언어 변경은 같은 IA를 유지한다.

## 다음 판단 근거

첫 책 보관, 초대받은 상대의 참여, 상대의 실제 기록 추가, 같은 책장의 두 번째 책을 본다. 조회수나 칭찬만으로 수요를 판단하지 않는다. 현재 자동 집계가 없는 단계는 수집된 지표처럼 표현하지 않는다.

## 이번 변경 검증

- TypeScript, 변경 컴포넌트 ESLint, 프로덕션 빌드 통과.
- 기존 추억책 렌더링·경로·초대 개인정보 테스트 16개 통과.
- 별도 QA 사용자 3명으로 책장 생성, 초대 미리보기와 참여, 상대의 기록 열람·추가, 개인 기록 격리, 외부인 접근 차단, 소유자만 초대 생성, 초대 폐기, 중복 저장 재시도를 실제 API로 검증했다.
- ego 브라우저에서 영문 책장 생성 → 사진 선택 → 공유 책장 선택 유지 → 완성본 업로드 → 보관한 책 열기 → 초대 링크 생성 확인.
- 한·영 화면, 모바일 가로 넘침 없음과 소개 스크롤 확인. 사용한 QA 사용자·책장·앨범·생성 이미지 정리 완료.
- 로컬 구현 검증이며 이번 요청에서 운영 배포는 수행하지 않았다.

## 한 화면 완성 흐름 개선 (2026-10-27)

- 완성 화면에서 새 비공개 책장 이름 입력 → 책장 생성 및 보관 → 초대 생성·복사·만료까지 진행한다. 기존 책장과 개인 보관도 선택 가능하다.
- 보관을 주 행동으로 두고 다운로드·문구 수정·디자인은 접힌 보조 영역으로 배치했다.
- 랜딩은 커플의 여행·주말·기념일 예시로 통일하고, 예시 책을 펼쳐 두 사람의 기억을 읽도록 했다. 예시 페이지 구성임을 명시한다.
- 생성 재시도에 같은 UUID를 사용하여 책장 중복 생성을 방지한다. 다른 소유자의 ID 재사용은 거절한다. 초대 실패는 이미 저장한 책을 취소하지 않는다.
- 렌더링 및 책장 생성 테스트 10개, TypeScript, ESLint, 프로덕션 빌드 통과. 실제 API로 초대 참여·기록 추가·개인 격리·폐기를 검증했다.
- ego에서 사진만으로 2쪽 책 제작, 새 책장 생성·보관·초대 복사·만료를 확인했다. 모바일 너비 390px에서 가로 넘침 없음. QA 책장·앨범·생성 이미지 삭제 완료. 운영 배포는 수행하지 않았다.
