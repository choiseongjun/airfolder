# 여행 앨범 사용성 검증

목표: 최근 여행을 다녀온 사람이 설명 없이 앨범을 완성하고, 함께 간 친구에게 보내고, 친구가 사진을 보태는지 확인한다.

## 5명에게 부탁할 과제

최근 친구와 여행한 사람 5명을 대상으로 각자의 사진으로 진행한다. 실제 연락과 모집은 운영자가 한다. 테스트 참여자의 사진이나 대화 내용을 분석 문서에 복사하지 않는다.

“지난 여행 사진을 여기서 앨범으로 만들고, 같이 간 친구에게 보내봐 주세요.”

처음에는 버튼 위치나 기능을 설명하지 않는다. 참여자가 멈춘 지점, 이해하지 못한 문구, 도움을 요청한 단계를 기록한다. 친구에게 보내는 것은 참여자가 직접 결정한다.

## 끝난 뒤 물어볼 것

- 이 앨범을 받은 친구는 무엇을 할 수 있다고 생각했나요?
- 사진을 그냥 단톡방에 보내는 것과 비교하면 어떤 점이 좋거나 번거로웠나요?
- 다음 여행에도 쓰겠다고 한다면, 무엇 때문에 다시 쓰고 싶나요?

## 판단

앨범 완성에서 막히면 제작 흐름부터 수정한다. 완성했지만 전송하지 않으면 실제 이유를 묻는다. 초대받은 친구가 사진을 보태지 못하면 받는 사람의 흐름을 관찰한다. 예쁘다는 평가와 재사용 행동을 구분한다. 다섯 명의 결과를 시장 전체의 전환율로 해석하지 않는다.

서버의 album_created는 빈 앨범 생성도 포함한다. upload_succeeded와 함께 보고, invite_created는 링크 생성이며 실제 전송을 뜻하지 않는다. invite_opened와 invite_joined 및 초대받은 사람의 upload_succeeded를 구분한다. 운영자·QA 접속과 이벤트는 고객 결과에서 제외한다.
