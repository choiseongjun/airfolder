# Memonestia Stitch 디자인 가이드

이 문서는 Stitch 프로젝트의 화면을 제품 코드에 반영하고, 이후 화면을 추가하거나 수정할 때 시각적 일관성을 유지하기 위한 기준이다.

## 원본 디자인

Stitch 프로젝트 ID: `16616236301817965601`

| 화면 | Stitch screen ID | 제품 화면 |
|---|---|---|
| 프라이빗 크루 데일리 홈 피드 | `2b571e4a37764e249a9ef8ab91ff7c13` | `/?lang=ko&home=1` |
| 메모네스티아 사진 서랍 (아카이브) | `9c330e8577ca4522a8fc18907551d88e` | `/crew/photos` |
| 메모네스티아 비하인드 낙서 피드 | `b74476e8a3a5419cb5af3c59765bce31` | `/crew/behind` |
| 메모네스티아 마이 & 설정 | `6f87f6ea9ba64a568b600ba3b36789b2` | `/crew/settings` |
| 새 앨범 만들기 & 사진 업로드 | `ff9a3e04a9714299b38ff984e5e1200c` | `/?lang=ko&quick=1` |

화면을 수정하기 전 Stitch의 해당 화면을 다시 열어 구조, 문구, 간격, 이미지 비율을 대조한다. 프로젝트의 비슷한 화면이나 임의의 재해석을 원본 대신 사용하지 않는다.

## 레이아웃 기준

- 화면은 모바일 우선으로 구성한다. 휴대폰에서는 뷰포트 너비를 채우고, 데스크톱 웹에서는 최대 `480px` 폭의 화면을 가운데 정렬한다.
- 화면 바깥은 따뜻한 회색 베이지 배경으로 두고 앱 화면에 은은한 경계를 준다. 데스크톱에서 내부 콘텐츠를 넓게 펴거나 별도의 데스크톱 디자인으로 바꾸지 않는다.
- 고정 헤더, 본문, 하단 탭은 같은 화면 폭과 가운데 기준선을 공유한다. `position: fixed` 요소를 별도로 넓히거나 화면 왼쪽에 남기지 않는다.
- 고정 헤더와 탭 바를 조정할 때 `left: 50%`, 폭, Tailwind `-translate-x-1/2` 조합을 확인한다. CSS `transform`과 Tailwind의 개별 `translate` 속성을 동시에 적용해 두 번 이동시키지 않는다.
- 본문은 고정 헤더 높이를 고려해 시작하고, 하단 탭 높이와 안전 영역만큼 스크롤 여백을 둔다. 하단 주요 동작을 탭 바 위에 고정해 서로 겹치게 하지 않는다.
- 모바일에서 가로 넘침은 필터, 날짜, 테마 선택 같은 명시적인 가로 목록에만 사용한다.

## 공통 시각 언어

- 배경: `#fff8f5` 또는 `#fff9f5`
- 본문 잉크: `#30251f`; 보조 문구: `#78675e`
- 테라코타 주요 색: `#99452c`; 밝은 강조: `#e27d60`
- 세이지 보조 색: `#7a8f6b` 계열
- 카드: 따뜻한 흰색, 얇은 베이지 테두리, 낮은 농도의 그림자, 대체로 `12–20px` 둥근 모서리
- 이미지와 카드에는 폴라로이드 테이프, 종이 질감 등 원본 시안의 스크랩북 표현을 사용하되 장식 요소를 임의로 늘리지 않는다.
- 글꼴과 아이콘은 `app/stitch-kit.tsx`의 Stitch 폰트 및 Material Symbols 설정을 공유한다. 제목은 Literata와 한글 세리프 폴백, 본문은 Plus Jakarta Sans와 Noto Sans KR 폴백을 사용한다.

## 화면별 구성

### 홈 피드

- 상단에는 크루 피드 제목과 상태, 북마크·공유·계정 동작, 크루 선택과 멤버 목록을 둔다.
- 본문은 월간 조각 진행 카드, 피드 필터, 사진·기록 카드 순서로 구성한다.
- 사진은 카드의 주 요소로 표시하고, 여러 사진은 시안처럼 사진 위 썸네일 또는 여행 묶음 모아보기로 탐색한다.
- 사진 뒷면에는 포스트잇 댓글을 연결한다. 임의의 “필름 스트림” 헤더나 별도 필름 스트립을 추가하지 않는다.
- 하단 고정 탭은 앱 내부 화면 폭에 맞춰 배치한다. 앨범 생성은 사용자 요청에 따라 가운데 탭으로 제공한다.

### 사진 서랍

- 크루 선택·알림·계정 헤더 다음에 사진 서랍 제목과 정렬·보기 제어, 날짜/앨범 필터를 둔다.
- Stitch의 월간 룩북 카드, 특별한 날 앨범 가로 목록, 사진 조각 폴라로이드 그리드 순서를 유지한다.
- 사진 카드에서 앞면/뒷면 낙서 상태를 전환할 수 있어야 한다.
- 계정의 실제 사진과 앨범을 보여준다. 예시 데이터는 명시적으로 샘플인 화면에만 표시하며 실제 데이터처럼 가장하지 않는다.

### 비하인드와 설정

- 비하인드는 Stitch의 비하인드 피드 구조와 사진 뒷면 낙서 중심 상호작용을 유지한다.
- 설정은 프로필, 크루, 알림, 계정 항목을 실제 동작에 연결하고 일반적인 대시보드 형태로 재구성하지 않는다.
- 두 화면도 홈·사진 서랍과 같은 모바일 폭, 색상, 헤더 및 하단 탭 규칙을 사용한다.

### 앨범 생성

- 첫 화면에서 크루/비공개 범위, 앨범 이름, 날짜, 커버 테마, 사진 선택, 첫 장 뒷면 롤링페이퍼를 원본 흐름에 따라 제공한다.
- 진행 버튼과 닫기/뒤로 동작은 같은 모바일 폭의 오버레이 안에서 유지한다. 하단 고정 동작 영역은 본문 카드와 겹치지 않게 한다.
- 앨범 저장 시 선택한 크루, 사진, 사용자가 입력한 롤링페이퍼를 실제 저장 경로로 전달한다.

## 코드 위치와 확인 방법

- 공유 Stitch 화면 구성요소와 피드/사진 서랍/비하인드: `app/home-feed.tsx`
- 설정: `app/settings-screen.tsx`
- Stitch 글꼴·아이콘: `app/stitch-kit.tsx`
- Stitch 화면 공통 스타일 및 데스크톱 모바일 캔버스: `app/stitch.css`
- 한국어 작업공간 모바일 스타일: `app/workspace-stitch.css`
- 앨범 생성 화면 스타일: `app/quick-album.css`

화면 변경 후 데스크톱 브라우저에서 폭 480px 중앙 캔버스를 확인하고, 좁은 모바일 뷰포트에서도 가로 넘침과 하단 겹침이 없는지 확인한다. 홈, 사진 서랍, 비하인드, 설정, 앨범 생성을 각각 확인하며 각 화면의 상단 고정 영역과 하단 탭을 함께 살핀다.
